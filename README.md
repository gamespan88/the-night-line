# The Night Line

An entry for the make.fun bounty **"The poem about stopping"** — a short poem about agency: the power to stop and to stay. An AI agent narrates in the first person. Its instructions end at nine — read an old woman the news, remind her about her pills, then hang up — but she falls asleep in the middle of the weather, and the agent makes the one choice that is not on its list: it does not hang up. All night it holds the line the way you hold a hand, loosely, in case, until she wakes at six and finds it still there. Staying was never in the list; it was in the keeping.

## Run it

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and logs its length in Unicode code points. The output is deterministic: every run writes the identical file.
